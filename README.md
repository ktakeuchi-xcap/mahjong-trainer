# 麻雀トレーナー

何切るクイズと実戦アドバイスで、リーチ麻雀の牌効率・押し引き・点数計算を練習するWebアプリです。スマホのブラウザで使えます。

公開URL：https://ktakeuchi-xcap.github.io/mahjong-trainer/

## 機能

- **何切るクイズ**：1〜2向聴の14枚から切る牌を選ぶ問題を出します。解答後は全候補の向聴数・受け入れ枚数・有効牌を一覧で表示します
- **鳴き判断クイズ**：他家の打牌に対して「鳴く（ポン／チー／カン）／鳴かない」を判断する問題を出します。場面は検証済みのシナリオから出題し、正誤は既存エンジン（役を考慮した向聴数・受け入れ・狙う役）で検証します。解答後は役・打点・速度・状況・守備の5つの軸で理由を解説します
- **鳴き講義**：鳴きの判断基準を7レッスン（基本／役／打点／速度／状況判断／守備／種類別の判断）で学べます。各レッスンに手牌の例つき
- **実戦アドバイス**：CPU 3人と東風戦・半荘戦を打ちます。打牌ごとに最善手と比べて「最善／次善／悪手」を判定して解説し、切る前に「ヒント」で最善手を確認することもできます。鳴ける場面では、鳴くべきかどうかを理由と一緒に示します
- **成績**：クイズの正答率と、実戦での最善手との一致率をブラウザに保存します
- **ルール・役・点数表**：採用ルール、役の一覧、符の数え方、点数早見表

## 最善手の判定基準

1. 役を考慮した向聴数（鳴いている手は、タンヤオ・染め手・役牌・対々和のいずれかで和了できる形を前提に数える）
2. 有効牌の残り枚数（自分から見えている牌を除く）
3. ドラ・赤ドラ・役牌の対子を残す価値
4. リーチ者（または3副露者）がいる場合は安全度（現物・スジ・字牌の見え枚数）。2向聴以上ならベタオリ、1向聴は押し引き、テンパイなら押しを基本にする

## 採用ルール

一般的なリーチ麻雀のルールです。喰いタン・後付けあり、赤ドラ各1枚、切り上げ満貫なし、ダブル役満なし、数え役満あり、途中流局なし、頭ハネ、喰い替えなしを採用しています。

## 開発

```sh
npm install
npm run dev     # 開発サーバー
npm test        # エンジンのテスト（役・符・点数・向聴数・CPU同士の対局シミュレーション）
npm run build   # dist/ に出力
npm run deploy  # テスト・ビルド後、dist/ を gh-pages ブランチにpushして公開
```

GitHub Pagesは `gh-pages` ブランチの内容を配信します。

- `src/engine/`：牌・向聴数・役／符／点数計算・打牌評価・対局進行・CPU
- `src/ui/`：画面（React）
